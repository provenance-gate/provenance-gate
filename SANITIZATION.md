# Sanitization Notes

This public repository was created as a fresh, zero-history package.

Included:

- minimal provenance gate implementation,
- minimal examples and tests,
- public article draft,
- two cropped/public screenshots.

Excluded:

- private raw evidence,
- local machine paths,
- customer or business records,
- private project logs,
- original private repository history,
- unpublished internal operation docs.

The private working repositories remain private and are not made public by this
package.
